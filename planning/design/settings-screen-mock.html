Degraded values stay legible (dashed borders mark read-only, not grayed-out). Cards degrade independently — the brief keeps rendering if its own source is readable. Empty is not an error: steward-voiced lines, no banner. Loading is a plain "Loading…" line, no spinner. A failed save reverts the control and re-raises the storage banner. A hard settings failure replaces only the content column — header, rail, and chat never blank. Voice controls with no drop-dir configured disable with an explanation line (not shown: identical layout to Board 3's Microphone card with the three controls disabled).
