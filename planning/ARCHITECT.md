> The altitude **above** the contract. `planning/contract.yaml` is the source of truth (DEC-*, governance, epics, tickets); this file is the one-page spine, the live blockers, and the decision log. Maintained by the `architect` agent. Last synced: 2026-07-02 (contract v0.70, stage `analyze`).

## What wombat is

A quiet, deterministic personal assistant — "The Steward" — where the **LLM is a mouth, not a brain**. Built as a pure **adopter of the local cog-worx** cognitive framework (Stages + pathways on its Engine; never forks the Engine). The product thesis rides on a deterministic **interruption gate**: a two-axis **Urgency × Cognitive Load** pressure engine with **no LLM in the decision**.

## The locked spine (DEC-1..DEC-19 — do not change without escalation)

- **Gate (DEC-1/13):** two-axis Urgency × Cognitive Load, deterministic code between the queue and the loop; per-event ratings, personalized + adaptive; Cognitive Load cumulative across a durable pending set.
- **cog-worx mapping (DEC-12):** wombat = Stages + pathways on cog-worx's Engine; no loop code, no forked Engine.
- **Loop (DEC-8/14):** one queue-driven drain pathway; pluggable input sources register with a source registry; idles on empty.
- **Memory (DEC-11, supersedes DEC-2; DEC-15):** cog-worx user_model scope + a thin PA empirical-user-model layer; behavior + outcomes only, never motive. The dev agent-memory pipeline is a *separate, out-of-scope* layer.
- **Mouth (DEC-4/18):** DeepSeek (cloud, OpenAI-compat) via the cog-worx S4 seam, behind the budget guard; renders pre-decided output only.
- **Brief & dreaming (DEC-16/17/23):** morning brief = scheduled pathway = one forced flush through the gate (selects its own items via the gate's threshold-free `select_items` seam, never the live pending set); nightly "dreaming" = off-path batch pathway that re-tunes ratings. **DEC-23:** off-path (S1) consolidation-time LLM inference IS admitted in the dream pathway (the cog-worx reconciler/extractor use a model-backed oracle) — the GATE stays model-free (NG-4 governs the gate, not off-path consolidation; bounded by a BudgetGuard).
- **Side effects (DEC-19):** journal trail + review-before-send via `AwaitHuman` and the cog-worx approval gate.
- **External tier (DEC-20 + DEC-22):** the cog-worx `external` capability tier is admitted ONLY for the approved AwaitHuman dispatch stages (Gmail draft, browser); engine default stays `{read,write}`. The planning **authorization is GRANTED** (DEC-22, settled by architect under Jim's delegation). The only remaining act is the **build-time enablement** of the cog-worx external-tier flag in deploy config — a TK-151 bring-up step, not a planning blocker; TK-151 fails closed until that flag is set (wombat never self-grants at runtime).
- **Wombat-day (DEC-21):** the canonical day is the **civil-local date** in a configured IANA timezone, computed at access time (survives laptop sleep across midnight); one shared `DailyLedger` primitive (TK-152) owns the boundary for spend/ceiling/brief ledgers.
- **Scope (DEC-3/6/7/9/10):** v1 = read-only Google Calendar + Gmail-only → one combined morning brief; voice + browser in v1; runs on a laptop.

## v1 scope boundary

IN: read-only calendar, Gmail-only (incl. drafts via review-before-send), one combined morning brief, voice input source, browser/computer use, laptop deployment.
OUT / deferred: always-on hardware, non-Gmail email, sending without review, the dev agent-memory RAG pipeline.
